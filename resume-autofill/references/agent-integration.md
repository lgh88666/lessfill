# 跨 Agent 工具适配

仅在首次进入新宿主、工具能力变动或实际缺能力时读取；正常填表复用已建立连接和已保存配置。

## 调用方式

- 支持 Agent Skills 的客户端：加载整个 `resume-autofill/` 目录，保留 `SKILL.md`、`references/`、`examples/` 的相对结构。安装目录依客户端文档，不能假设所有宿主扫描同一位置。
- 不支持原生 skill、但能读本地文件的 Agent：用户给出绝对 `SKILL.md` 路径后，读取它；按其中链接读取必要参考，而非一次注入全部仓库。
- 自定义 harness：可把 name/description 放进技能目录，只在选中时加载正文，并提供读取相对参考文件的工具。核心入口不要求专用 slash command，也不要求识别 `agents/openai.yaml`。

仅把网址贴给纯聊天模型不会赋予它浏览器或文件操作能力。云端 Agent 读不到用户电脑上的文件时，需要上传文件或已授权的文件传输；不把本地路径误报为可用文件。

## 按能力映射，不按工具名称绑定

|需要的能力|可接受的实现|缺少时如何处理|
|---|---|---|
|读配置及资料|宿主文件读取、工作区工具或获准的文件 API|请用户提供文件/可访问目录；不假装已读取|
|解析简历|PDF/DOCX 读取、文档提取、必要时 OCR|报告格式或解析阻碍，不自行补全事实|
|保存私人状态|宿主文件编辑、工作区写入或用户指定的私人持久存储|说明无法持久保存；仍可进行明确授权的本次操作，交付需保存的内容|
|取得浏览器目标|所选路线提供的标签列表、会话状态及页面网址|只报告该通道故障；不假定另一会话登录失效|
|字段读写|Playwright locator/结构化表单工具、Jev 或等价字段接口|特殊控件局部回退，禁止默认逐屏逐格截图|
|上传附件|file input、文件选择器或宿主文件传输|保留现场，请用户完成缺少的上传，不切换未授权浏览器|
|飞书浏览器操作|同一所选浏览器中的飞书目标页|留本地 pending 项，不要求接入 MCP|
|飞书 MCP 操作|实际提供的创建、字段、查询与记录写入能力|按用户是否允许回退处理，不把记录读写当建表能力|

优先按 `auto` 检查 WorkBuddy、豆包工作任务等宿主是否已经提供可用浏览器能力；没有才说明外部连接需求。`host-native`、Chrome＋Jev / Edge＋Playwright 的选择仍按用户配置。这里的“等价能力”不授权转移登录 cookie 或绕过页面校验。

## 可选宿主功能

- 聊天改名、截图交付、特定 UI 面板、弹出提问等属于宿主能力，不是填表前置条件。没有专用提问工具时用普通对话集中询问。
- 只在当前工具确实存在时使用 Codex 的内置浏览器入口；不存在时直接使用已配置的 Playwright MCP 或 Jev，不搜索本机 Codex 运行时目录。
- 不硬编码 Node/Python 可执行文件、个人用户名、安装盘符、标签 ID 或环境凭据。
- 路径以当前宿主的文件系统为准。远端/容器路径不能当成用户 Windows 路径；不要自动改写到另一机器上的同名目录。

## 换 Agent 时延续记录

给新宿主明确的私人 `config.json` 路径，确保它可访问该目录和所选服务。复用 `profile.md`、tracker URL/ID 和 application_key；浏览器登录和 MCP 授权在新宿主单独建立，不复制凭据，也不因为换工具再创建飞书表。

这份文件定义调用与能力适配规则，不是已验证的客户端兼容列表。
