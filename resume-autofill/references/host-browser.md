# 宿主浏览器：WorkBuddy、豆包工作任务等

目标是使用桌面 Agent 当前已提供的网页、文件、上传及持久保存能力。这里不定义任何虚构的产品 API，也不把“支持导入技能”当成“支持浏览器控制”。

## 开始

查看当前实际工具说明，确认能否读取页面网址/内容、选择目标会话和编辑字段。仅搜索引擎、链接摘要或读取网页文本的能力不能完成填写。工具可操作时用其返回的目标页面确认招聘单位和登录状态；无须先安装 Playwright MCP 或 Jev。

宿主浏览器、浏览器连接器和桌面键鼠工具可能是不同会话，不假定与用户所有本机浏览器共享登录。按工具授权选择当前任务可操作的会话，登录和验证码由用户完成。系统不提供切页或文件输入时，说明具体限制，不循环要求用户切页。

## 填写与上传

- 优先结构化表单/字段接口，批量处理当前区块。只有截图/键鼠工具时按宿主规则操作并说明局限，不假称有 DOM 能力。
- 简历和照片来自用户文件。检查当前上传接口是否能读到它们；只有文件读取能力不足以上传到网页。缺上传能力时保留已填内容并让用户补传。
- 只保存草稿，停在最终申请提交前。用户明确回答的长期事实写回私人 `profile.md`；无法写本地文件时交付补充内容并说明未持久保存。
- 飞书选择浏览器方式时复用同一授权网页能力；选择 MCP 时使用用户已接入连接器。不能把宿主内置的文档读取功能当成任意飞书表格写入权限。

## 能力缺失

报告具体缺少浏览器编辑、附件上传、文件持久化或飞书写入中的哪一项。仍可完成简历提取、资料补充和已获准字段的填写；剩余步骤明确交接，不声称整次网申完成。不把普通聊天、模型 API 或单纯技能导入视为完整执行环境。
