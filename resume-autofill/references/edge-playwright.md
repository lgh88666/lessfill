# Edge＋Playwright

优先复用能访问目标 Edge 标签的内置 Playwright 接口；其次独立 Playwright MCP。独立 MCP 的 browser channel/profile 配置不自动证明它连到了用户已登录窗口，须从当前标签及页面内容确认。

## 避免错误通道

宿主若提供 `cua_repl`，按其入口文档取得浏览器与标签清单，匹配用户链接，复用返回的目标标签及内置 Playwright。此名称是可选能力，不是所有 AI 工具都有；未提供即跳过。独立 `playwright` MCP 与 Windows `sky` 窗口接口是不同通道。MCP 仅有 Welcome/连接页或 Windows 读不到网址，不代表内置浏览器接口也不可用。

在要求用户重新登录、拖标签或切窗口前检查可用目标浏览器通道；得到有效连接后停止探测其他通道。浏览器/标签 ID 只来自当前工具返回值，不写进公共配置。

## 扩展模式

独立 MCP 使用扩展模式时，一次发起连接；若停在授权/选页页，说明需要完成哪个已有连接，不反复发起、重启 MCP 或新建连接标签。只在实际需要时让用户选网申标签或将其加入当前连接的标签组；目标已可访问就不再要求拖标签。

不同客户端可能拥有独立标签组/范围，只操作本次获准的标签。不抢其他聊天标签、不清理其他连接页。免批准凭据由 MCP 配置管理，不能承诺它会消除所有连接页面。

## 表单

依据工具实际支持的 locator、结构化填表或批量执行能力操作，不假定所有封装都支持完整 Playwright API。读取当前区块结构后，把不依赖动态结果的字段成批填写。动态新增/切页后刷新相关定位，失效字段局部恢复。不移除 readonly、注入值或绕过校验。

日期通过真实控件或工具支持的普通字段输入，按目标粒度填写；不为无日信息擅自编造日期。上传用工具支持的 file input/文件选择器接口，见 [files.md](files.md)。截图和键鼠回退仅用于局部控件，使用前读取宿主对应规则。

若用户本轮选择 Edge，不因连接失败自行转到 Jev Chrome。已打开的其他浏览器目标页仅在用户已允许该路径时复用，并分别判断登录状态。报告具体连接阶段和错误，不把窗口标题当成网址或登录证据。
