# Chrome＋Jev

用户选择此路径即允许使用 Jev 所控制的 Chrome；不要承诺它与用户其他 Chrome 窗口共享登录。若已安装 Jev skill，先按它的入口及当前工具 schema 操作；未安装对应 skill 时只使用已提供且文档明确的工具，不臆造方法。

## 连接

- 首次以状态工具确认模式。Jev browser mode 可能启动独立的持久 Chrome 配置；extension mode 操作扩展授权的现有 Chrome。说明实际模式，用户在该会话登录一次后复用。
- 已有本次任务授权目标标签时复用；需开新标签时遵循该模式的工具规则，保留用户未保存页面。不自行改用户浏览器配置、导入 cookie 或把密码交给 Jev。
- 状态未连接时说明一次具体连接操作；不要循环重连。`jev_*` 不可用但基础 `browser_*` 可用时可用基础工具继续，报告真正的限制。

## 填写

多步区块任务可用 `jev_task`，仅传该区块需输入的确切字段值、完成条件及“允许保存、禁止最终提交”的边界。不要把整个个人资料文件、其他投递记录或无关敏感字段放进 goal/details。Jev 可能使用独立服务和计费；首次启用代理任务时按工具配置和用户授权说明，不承诺包含在宿主会员额度内。

读取结果区分 `done`、`needs_input`、`needs_confirmation`、`blocked` 等实际状态；不把代理自报完成当最终提交成功。只查看必要操作反馈，不再整表复查。不得为完成填表打开 `allowIrreversible` 或让代理自动投递。

上传依据 [files.md](files.md) 检查现有工具能力。登录、验证码、签名和用户尚未授权的对外操作按当前宿主/工具规则处理。
