# 网申填写与投递记录

## 入口与私人状态

接受招聘网址、简历本地路径或可访问链接、可选照片路径及浏览器偏好。用户明确提供的文件用于本次网申上传；只有简历而没有照片时先填可确定的内容，照片必填再询问，不虚构照片或身份事实。

先解析私人配置：用户指定的配置文件优先，其次使用当前工作目录 `.resume-autofill/config.json`。没有配置时按[首次使用](references/setup.md)初始化。配置和资料文件的相对路径以配置文件所在目录为基准；示例不会自动成为用户配置。私人文件存放在本地工作目录或用户指定的私人目录，不写入 skill 安装目录。不会因换聊天而重建资料或飞书表。

每次任务读取当前配置和配置指定的资料文件；简历首次导入或文件更新时读取简历并更新来源明确的资料，保留用户后来纠正的事实。敏感资料只按当前网申字段按需读取和传入工具；不得把完整资料默认塞进浏览器代理任务。简历导入、远程文件及附件规则见[文件与上传](references/files.md)。

把填表追问用于逐步完善私人资料：先读取已有文档，只询问当前任务真正缺失或冲突的字段；优先集中询问，先做不依赖答案的部分。用户回答后，将明确确认且可复用的个人事实补入配置指定的 `profile.md` 对应条目，标注确认日期/来源，保留其他内容并简短告知已记录；用户要求不保存时遵从。本次岗位薪资、意向城市等临时答案只保存在本次申请，不自行升级为长期偏好。新回答纠正旧事实时更新当前值，不能让旧简历再次覆盖。后续任务重新读取后复用，不重复追问已知答案。首次交接提醒用户：可以持续回答 Agent 的问题完善该文档，也可以直接编辑。

飞书首次初始化时让用户选择 `browser`（浏览器建表及登记，无需飞书 MCP）或 `mcp`（使用用户已接入的飞书 MCP），保存为 `tracker.transport`。已有明确选择则直接复用；未选择时不因检测到 MCP 就默认采用。浏览器模式不探测或安装飞书 MCP；MCP 模式不擅自申请凭据或切回浏览器，除非用户已允许回退。工具缺失时先完成可做的网申并保留待登记项。

## 选择浏览器

用户本轮明确选择优先，其次按配置。支持两条路径，仅读所选路径的参考：

- `chrome-jev`：使用 [Chrome＋Jev](references/chrome-jev.md)。
- `edge-playwright`：使用 [Edge＋Playwright](references/edge-playwright.md)。

首次未选择且已有有效目标连接时可直接复用；否则集中询问一次，与简历、照片、飞书初始化信息一起收集。不得以不同会话的登录页推断用户原会话未登录。只操作工具实际返回且已确认的网址及目标标签；找不到目标时按所选浏览器支持的导航方式打开。未保存页面不刷新、关闭或覆盖。一个接口失败不代表所有接口均不可用。

## 填写与权限

1. 确认招聘网站、公司、岗位及可编辑状态，先填已明确的事实。已有条目先匹配，避免重复添加。缺少的必填事实集中询问；未知不等于“无”，成绩、奖项、技能、亲属任职等不统一编造默认值。
2. 按区块批量填写。普通字段优先结构化定位器或字段接口，动态下拉和日期按实际控件分批处理。只读取当前所需字段、选项或变化，避免逐字段整页快照和截图。截图仅用于字段接口无法处理的控件。
3. 按用户指定的附件类型自动上传已授权简历及照片；证件、成绩单和其他证明文件不套用照片/简历授权。上传与数据输入授权依本轮请求、持久偏好及宿主规则判断，skill 本身不替用户授权。
4. 默认允许保存、暂存和只推进编辑的“下一步”；禁止最终投递、提交申请或向招聘方发送申请。按钮功能不明先读提示，不能只按名称判断。登录、密码、验证码及法律签名按宿主工具规则交给用户。
5. 默认由用户做最终内容检查，不整表回读。工具报错、附件拒收、保存失败等仍需处理；以必要成功提示确认保存或上传，不把“尝试点击”报告为已成功。
6. 填写过程中提取本次公司、岗位、工作地点和招聘链接。按[飞书投递表](references/feishu.md)登记：未提交时默认“待提交”；仅用户明确指定其他记账口径时按配置写入，不据此宣称已提交。
7. 简短交接：实际已填/已保存、附件结果、缺失或阻碍、是否提交、飞书登记结果及表格链接。保留当前编辑现场。若未完成后续页面，不报告完成；可更新既有记录为“填写中”。

## 执行故障

连接故障只按当前工具错误恢复一次，有新依据才继续尝试。扩展等待连接时明确指出现有连接页所需动作，不循环发起连接。外部写入超时先查询结果，禁止盲目重试新增表格或记录。配置缺失、登录未完成、权限不足须报告具体阶段；不在正常填表中安装软件或申请额外云权限。

飞书能力缺失不阻止可进行的网申填写；在私人状态中留下待登记项，恢复后补写，不声称已登记。用户更新浏览器选择、资料或上传权限时仅修改相应私人配置，不改变公共 skill。
